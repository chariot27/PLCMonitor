# 05 - Monitoramento e Debug

Uma das partes mais poderosas do ISPSoft é a sua capacidade de diagnóstico.

## 1. Modo Online
Ao clicar no ícone "Online Mode", o ISPSoft mostra o estado real dos contatos e valores dos registradores em tempo real no Ladder.
- **Contatos Verdes**: Energizados.
- **Valores em Azul**: Valor atual da variável.

## 2. Device Monitor
Uma tabela onde você pode listar várias variáveis de diferentes partes do programa para monitorar simultaneamente sem precisar navegar pelas POUs.
- Permite "Forçar" (Force) o estado de uma entrada ou saída para testes, ignorando a lógica do programa.

## 3. Upload e Download
- **Download**: Envia o programa do PC para o CLP (Cuidado: pode parar a máquina!).
- **Upload**: Busca o programa que está dentro do CLP para o PC.
*Dica: No ISPSoft, você pode baixar o código com ou sem os comentários/símbolos. Sempre baixe com símbolos se houver espaço na memória do CLP para facilitar manutenções futuras.*
